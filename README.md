# Royalty Desk

Helps inventors approach China OEM/ODM manufacturers for royalty and joint-development deals, with no upfront tooling cash.

**Works now (free, no account):** the partner kit on the page. Free keyless AI drafts a non-confidential one-pager and a first message to a factory. You also get ready-made searches on Alibaba, Made-in-China, Global Sources and Google Patents, plus trademark links and a protect-first checklist (NNN agreement, China first-to-file trademark, factory vetting, royalty terms). The draft is saved only in the visitor's browser (localStorage). Nothing is sent to Royalty Desk, and visitors send any messages themselves.

**Not open yet:** operator-led matching and success fees. The page says so plainly. Opening it needs a public intake inbox and agreed engagement terms.

Static files: `index.html`, `kit.js`, `ai-helper.js`, `assets/`.
